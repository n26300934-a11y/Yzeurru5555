# PhoneAssistant

نسخه آماده برای ساخت APK با GitHub Actions.

## ساخت APK
1. کل محتوای این پروژه را در ریشه Repository قرار بده.
2. وارد تب **Actions** شو.
3. Workflow با نام **Build APK** را انتخاب کن.
4. روی **Run workflow** بزن.
5. بعد از اتمام Build، وارد اجرای موفق شو.
6. پایین صفحه بخش **Artifacts**، فایل `PhoneAssistant-debug-apk` را دانلود کن.
7. ZIP دانلودشده را باز کن و `app-debug.apk` را روی گوشی نصب کن.

> برای کنترل رابط کاربری برنامه‌ها باید Accessibility را بعد از نصب، از تنظیمات گوشی فعال کنی.
