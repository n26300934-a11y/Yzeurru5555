# Phone Assistant — نسخه اول

این پروژه یک دستیار اندرویدی پایه است که:
- دستور متنی می‌گیرد.
- Accessibility Service دارد.
- می‌تواند بعضی برنامه‌ها را باز کند.
- می‌تواند متن قابل‌مشاهده رابط کاربری را بخواند.
- زیرساخت کلیک روی عناصر رابط کاربری و gesture را دارد.

## اجرا
1. پروژه را در Android Studio باز کن.
2. Gradle Sync را انجام بده.
3. روی گوشی Android 8 یا بالاتر اجرا کن.
4. داخل برنامه روی «فعال‌کردن دسترسی دستیار» بزن.
5. Accessibility > Phone Assistant را فعال کن.
6. بعد دستورهای آزمایشی مثل «تلگرام را باز کن» را امتحان کن.

## نکته
این نسخه عمداً ساخت انبوه حساب، جمع‌آوری خودکار رمز/کد 2FA و دورزدن محدودیت‌های سرویس‌ها را پیاده‌سازی نمی‌کند.
